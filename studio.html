Danh Mục Toàn Bộ Dự Án Sách

Tự động đồng bộ với tệp data/books.json của thư viện. Bấm vào "Chỉnh sửa" để tải thông tin cuốn sách đó vào bảng biên tập.

Quy Trình Đồng Bộ Lên GitHub Pages (2 Phút)

Mỗi khi bạn nạp sách mới hoặc cập nhật chương từ Studio, quy trình đẩy lên GitHub chỉ gồm 2 bước:

  1. Bấm nút "Đóng Gói & Tải File ZIP": Studio sẽ tự động tạo file ZIP chứa chuẩn cấu trúc thư mục gồm file data/books.json đã gộp, thư mục content/books/<tên-sách>/ (gồm ảnh bìa và các file chương .md), cùng file content/downloads/<tên-sách>.txt.
  2. Giải nén và kéo thả vào GitHub: Bạn giải nén file ZIP ra thư mục dự án máy tính hoặc kéo thả trực tiếp vào kho lưu trữ trên web GitHub (nút Add file -> Upload files) rồi bấm Commit changes.
  3. Trang web tự động cập nhật: Trong vòng 30 giây, GitHub Pages sẽ tự động xuất bản cuốn sách mới lên web đọc online toàn cầu!
